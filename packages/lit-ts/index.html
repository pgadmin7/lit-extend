Composition + Lit

Motivation

I love Lit web components but really dislike using Typescript decorators. Although I do understand the use of classes with custom elements. It still sometimes creates unnecessary typing complexity especially working with mixins in TS.

Vue went through a similar struggle before Vue 3 and decided to drop its Class API support. vue-class-component

The solution was the Composition API and its reactivity system. It enables clean logic reuse with flexible code organization.

Why not to bring that feature to lit?
